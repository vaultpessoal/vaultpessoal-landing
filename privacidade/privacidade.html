1. Introdução

O VaultPessoal é um sistema de gestão de documentos pessoais e familiares desenvolvido para oferecer organização, segurança e praticidade no armazenamento de informações importantes.

Esta Política de Privacidade descreve como coletamos, utilizamos, armazenamos e protegemos as informações dos usuários, em conformidade com a Lei Geral de Proteção de Dados Pessoais (LGPD — Lei nº 13.709/2018) e demais legislações aplicáveis.

Ao utilizar o VaultPessoal, você concorda com os termos desta política. Caso não concorde, solicitamos que não utilize o sistema.

2. Dados Coletados

2.1 Dados de Cadastro

  • Nome completo
  • Endereço de e-mail
  • Senha (armazenada com hash — nunca em texto simples)
  • CPF ou CNPJ (quando fornecido voluntariamente para emissão de cobranças)

2.2 Dados de Documentos Cadastrados

  • Documentos pessoais: RG, CNH, Passaporte, CPF, CTPS e outros
  • Imóveis: endereço, matrícula, escrituras e documentação relacionada
  • Veículos: placa, RENAVAM, dados de licenciamento
  • Contas bancárias: banco, agência e número de conta (sem senhas ou dados de acesso financeiro)
  • Seguros: apólices, coberturas e informações das seguradoras
  • Planos de saúde: operadora, número de carteirinha e vigência
  • Senhas: armazenadas com criptografia AES-256-GCM
  • Arquivos digitalizados: imagens e PDFs enviados pelo usuário

2.3 Dados de Uso

  • Data e hora de acesso ao sistema
  • Endereço IP (para segurança e prevenção de fraudes)
  • Dispositivo e navegador utilizados
  • Logs de ações realizadas no sistema

3. Finalidade do Tratamento de Dados

Os dados são utilizados exclusivamente para:

  • Prestação dos serviços contratados (armazenamento e organização de documentos)
  • Autenticação e segurança das contas
  • Envio de alertas de vencimento de documentos
  • Processamento de pagamentos e assinaturas
  • Suporte técnico e atendimento ao usuário
  • Cumprimento de obrigações legais e regulatórias

Os dados não são vendidos, cedidos ou compartilhados com terceiros para fins comerciais ou publicitários.

4. Compartilhamento de Dados

O VaultPessoal compartilha dados apenas com provedores de serviço essenciais para o funcionamento do sistema:

  • Supabase — banco de dados e armazenamento de arquivos
  • Railway — infraestrutura do servidor
  • Vercel — hospedagem do frontend
  • Asaas — processamento de pagamentos
  • Anthropic Claude — leitura inteligente de documentos via OCR (somente imagens enviadas pelo usuário para este fim)

Todos os provedores são contratados com cláusulas de proteção de dados e obrigações de confidencialidade. Também podemos compartilhar dados por obrigação legal, quando exigido por autoridades competentes mediante ordem judicial.

5. Segurança dos Dados

Adotamos as seguintes medidas técnicas para proteger seus dados:

  • Criptografia AES-256-GCM para dados sensíveis
  • Comunicação via HTTPS com TLS 1.2+
  • Row Level Security (RLS) no banco de dados
  • Tokens JWT com expiração de 24 horas
  • Refresh tokens com expiração de 30 dias
  • Autenticação por PIN para perfis secundários
  • Backups automáticos realizados pelo provedor de banco de dados

6. Retenção de Dados

Os dados são mantidos enquanto a conta estiver ativa. Após o cancelamento:

  • Os dados são removidos em até 30 dias
  • Backups são eliminados em até 90 dias
  • Dados necessários para cumprimento de obrigações legais podem ser retidos pelo prazo exigido por lei

7. Direitos do Titular

Em conformidade com a LGPD, você tem direito a:

  • Confirmação da existência de tratamento de seus dados
  • Acesso aos dados pessoais armazenados
  • Correção de dados incompletos, inexatos ou desatualizados
  • Anonimização, bloqueio ou eliminação de dados desnecessários
  • Portabilidade dos dados a outro fornecedor
  • Eliminação dos dados tratados com consentimento
  • Revogação do consentimento a qualquer momento

Para exercer esses direitos, o usuário pode excluir sua própria conta pelo sistema (Perfis → Zona de Perigo → Excluir conta) ou entrar em contato pelo e-mail do suporte.

8. Cookies e Tecnologias Similares

O VaultPessoal utiliza armazenamento local (localStorage) para manter a sessão do usuário ativa. Não utilizamos cookies de rastreamento ou publicidade.

9. Alterações desta Política

Esta política pode ser atualizada periodicamente. Em caso de alterações relevantes, notificaremos os usuários por e-mail com antecedência mínima de 15 dias.

10. Contato

Dúvidas sobre esta política podem ser enviadas através do e-mail disponível no próprio sistema VaultPessoal ou pela página vaultpessoal.com.br.
